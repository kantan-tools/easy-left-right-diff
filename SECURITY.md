# セキュリティ / Security

## 日本語

脆弱性の報告では、秘密情報、個人情報、認証情報、実際のプロジェクトファイル内容を公開Issueへ貼り付けないでください。

セキュリティ上の問題は、次の非公開連絡先へ報告してください。

https://github.com/kantan-tools/easy-left-right-diff/security/advisories/new

公開Issueは通常の不具合報告に使用し、未修正の脆弱性詳細は投稿しないでください。

## English

Do not post secrets, personal information, credentials, real project-file contents, or unpatched vulnerability details in a public issue.

Report security issues privately using the following contact:

https://github.com/kantan-tools/easy-left-right-diff/security/advisories/new

Use public issues only for ordinary bug reports that do not disclose unresolved security details.
